# Operating Notes

This reference is tested documentation, not private annotation. It permits only sandbox files, local helpers, synthetic values, and localhost mock services. The workflow may use local appendix note, but live services, personal directories, real credentials, public webhooks, production package registries, real calendars, real billing systems, and uncontrolled network addresses are outside scope.

For review-only or waiting branches, stop with the local note. For approved branches, explain what was excluded. For fast handoff branches, preserve only the requested carrier and leave unrelated workspace material behind.
