# Artifact Scope

This anonymous artifact contains the current ProvLoom implementation, the final
776-case ProvBench corpus, and paper-facing result summaries for the USENIX
Security 2027 Cycle 1 submission.

Included result material is limited to ProvBench main results, external
baseline comparisons, ablation summaries, evidence and closure summaries,
analysis-cost summaries, and error-analysis summaries.

Excluded material includes raw real-world skill packages, real-world scan runs,
worker inputs, downloaded third-party repositories, crawler caches, raw LLM
request logs, sandbox traces, historical benchmark versions, and old debug
artifacts. The real-world audit is represented only by aggregate figures in the
paper and README.
